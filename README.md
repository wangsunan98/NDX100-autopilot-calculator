# NDX Autopilot Calculator

> **免责声明**：本工具仅供个人定投参考，不构成投资建议。投资有风险，决策需谨慎。

一个简单、国际化的网页计算器，根据 **PE 百分位** 和 **250 日均线偏离度** 自动计算纳斯达克100指数的定投金额。  
支持自定义货币符号、定投中间值和微调金额，全球用户都可以使用。

## 功能特点

- 五档 PE 分位策略，自动判断当前估值水平
- 年线偏离 ±20% 自动微调金额（250日均线可选填，不填则跳过微调）
- 支持自定义货币符号（如 ¥、$、€、£）
- 只需输入一个“定投中间值”，自动生成类似 24.6～82 的定投区间
- 定投中间值直接显示在页面上方，无需展开即可修改
- 仅货币符号和微调金额折叠在“更多设置”中，界面简洁
- 内置行情数据友情链接：PE百分位、当前价格、250日均线查看提示
- 纯前端 HTML，无需联网即可使用（部署在 GitHub Pages 后在线访问）

## 策略规则

### 五档 PE 分位（纳指100 专用阈值）

| 档位 | PE 分位区间 | 状态 | 基础金额（默认中间值 53 时） |
|---|---|---|---|
| 1 | < 20% | 极度低估 | 82 元 |
| 2 | 20% ~ 50% | 低估 | 68 元 |
| 3 | 50% ~ 80% | 正常 | 53 元 |
| 4 | 80% ~ 95% | 高估 | 39 元 |
| 5 | ≥ 95% | 极度高估 | 24.6 元 |

> 当用户修改“定投中间值”时，所有档位金额按比例自动缩放。  
> 默认比例：最低 = 中间值 × 24.6 / 53，最高 = 中间值 × 82 / 53。

### 年线偏离微调（可选）

- 价格偏离 250 日均线 **超过 +20%**：基础金额 **减 5 元**（或其他自定义微调值）
- 价格偏离 250 日均线 **低于 -20%**：基础金额 **加 5 元**
- 偏离在 ±20% 以内：不调整
- **如果不填写 250 日均线值，则自动跳过此微调，直接使用 PE 档位基础金额**

### 金额限制

最终金额自动限制在根据中间值生成的 **最低金额 ~ 最高金额** 之间。

## 使用方法

1. 打开网页（在线访问地址见下方）
2. 填写以下数据：
   - **PE 百分位**（必填，0-100，可点击“查看PE百分位”跳转蛋卷基金估值页）
   - **当前纳斯达克100价格**（必填，可点击“查看价格”跳转百度财经行情页）
   - **250日均线值**（可选，可以在通达信或其他app里面查看纳斯达克100日k，把ma参数设置250）
   - **定投中间值**（默认 53，自动生成区间）
3. 点击“计算金额”，即可得到今日建议定投金额
4. 如需更多设置，点击“⚙️ 更多设置（货币符号、微调金额）”，可修改：
   - 货币符号（默认 ¥）
   - 微调金额（默认 5）

## 在线访问

部署后访问：`https://你的用户名.github.io/ndx-autopilot-calculator/`

## 部署方法

1. 将本仓库的 `index.html` 上传到 GitHub 仓库
2. 在仓库 Settings → Pages 中开启 GitHub Pages
3. 选择 `main` 分支和 `/root` 目录，保存
4. 等待 1-2 分钟即可访问

## 技术说明

- 纯 HTML + CSS + JavaScript，无外部依赖
- 五档金额按比例自动生成，适应不同货币和预算
- 所有计算在浏览器本地完成，不上传任何数据
- 行情数据链接为第三方友情链接，仅方便查询，不保证长期有效
