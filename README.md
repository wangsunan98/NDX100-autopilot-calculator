# NDX Autopilot Calculator

一个简单、国际化的网页计算器，根据 **PE 百分位** 和 **250 日均线偏离度** 自动计算纳斯达克100指数的每日/每周定投金额。  
支持自定义货币符号和金额区间，全球用户都可以使用。

## 功能特点

- 五档 PE 分位策略，自动判断当前估值水平
- 年线偏离 ±20% 自动微调金额
- 支持自定义货币符号（如 ¥、$、€、£）
- 支持自定义最低、最高定投金额和微调幅度
- 纯前端 HTML，无需联网即可使用（部署在 GitHub Pages 后在线访问）

## 策略规则

### 五档 PE 分位（纳指100 专用阈值）

| 档位 | PE 分位区间 | 状态 | 基础金额（默认人民币） |
|---|---|---|---|
| 1 | < 20% | 极度低估 | 82 元 |
| 2 | 20% ~ 50% | 低估 | 68 元 |
| 3 | 50% ~ 80% | 正常 | 53 元 |
| 4 | 80% ~ 95% | 高估 | 39 元 |
| 5 | ≥ 95% | 极度高估 | 24.6 元 |

### 年线偏离微调

- 价格偏离 250 日均线 **超过 +20%**：基础金额 **减 5 元**（或其他自定义微调值）
- 价格偏离 250 日均线 **低于 -20%**：基础金额 **加 5 元**
- 偏离在 ±20% 以内：不调整

### 金额限制

最终金额自动限制在用户设定的 **最低金额 ~ 最高金额** 之间（默认 24.6 ~ 82 元）。

## 使用方法

1. 打开网页（在线访问地址见下方）
2. 根据需要修改：
   - 货币符号（默认 ¥）
   - 最低定投金额（默认 24.6）
   - 最高定投金额（默认 82）
   - 微调金额（默认 5）
3. 输入市场数据：
   - PE 百分位（0-100，可从天天基金、雪球等平台查看）
   - 当前纳斯达克100价格（指数点位）
   - 250 日均线值（可在行情软件中查看）
4. 点击“计算金额”，即可得到今日建议定投金额

## 在线访问

部署后访问：`https://你的用户名.github.io/ndx-autopilot-calculator/`

## 部署方法

1. 将本仓库的 `index.html` 上传到 GitHub 仓库
2. 在仓库 Settings → Pages 中开启 GitHub Pages
3. 选择 `main` 分支和 `/root` 目录，保存
4. 等待 1-2 分钟即可访问

## 技术说明

- 纯 HTML + CSS + JavaScript，无外部依赖
- 五档金额按比例自动生成，适应不同货币和预算
- 所有计算在浏览器本地完成，不上传任何数据
