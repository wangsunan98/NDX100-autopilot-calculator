# ndx100-dingtou-calculator
# 纳指100 每日定投计算器

一个简单的网页工具，根据 PE 百分位和 250 日均线偏离度，自动计算纳指100每日定投金额。

## 策略规则

- 金额区间：24.6元 ~ 82元
- 五档 PE 分位（纳指100专用）：
  - PE < 20%：82元
  - 20% ≤ PE < 50%：68元
  - 50% ≤ PE < 80%：53元
  - 80% ≤ PE < 95%：39元
  - PE ≥ 95%：24.6元
- 年线偏离微调：价格偏离250日均线超过 ±20% 时，基础金额加减 5元，最终金额限制在区间内。

## 使用方法

1. 打开网页
2. 输入 PE 百分位（0-100）
3. 输入当前纳斯达克100价格
4. 输入 250 日均线值
5. 点击“计算金额”
